## 音階
１オクターブは、振動数で２倍の関係にあります。例えば高い「ド」の振動数は、低い「ド」の振動数の２倍になります。この関係を比率的に１２分割した音階が普通に使われています（平均律）。  
鍵盤で低い「ド」と高い「ド」を同時に弾いて、ステッピングモーターの回転数を比べてみてください。  
なお、「ド」と「ソ」の関係は、きれいな振動数の比（２対３）になるので、同時に鳴らすとハモリます。  
「ド」と「ミ」の関係は、（４対５）と言いたいところですが（平均律では）「ミ」が少し高めにズレます。 
音楽の時間に、「ミ」は気持ち低く歌ったほうが良いと習った人もいるかも知れませんね？
